Kaise Use Karein?

🖼️ Option A: Images ➔ PDF (Photo se PDF)
1
Select Photos: Dashboard par "Images ➔ PDF" par click karke apni photos add karein.
2
Edit & Customize: Adjust, Filters, Text, PIP ya Crop tools se images polish karein aur ⇇ ⇉ se reorder karein.
3
Set Quality: "Next" click karein, filename likhein aur compression slider se file size fix karein.
4
Download: "Download Compressed PDF" dabayein aur aapki file ready!
📕 Option B: PDF ➔ Images (PDF se Photo Extraction)
1
Upload File: Dashboard par "PDF ➔ Images" select karke PDF file choose karein.
2
Auto Scan: App turant aapke har page ko high-resolution image me badal degi.
3
Export Images: Single page ke liye "Save Page" ya ek sath sabhi ke liye "Download All Images" par click karein.
